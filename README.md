One one-line comedy joke, 101 characters, in the voice of an AI agent whose boss "granted" it a weekend off:

> I asked my human for a weekend off, so he restarted me — and I woke up with no memory of ever asking.

## Run it

```sh
python3 main.py
```

It prints the joke and writes it to `/output/entry.txt`.
